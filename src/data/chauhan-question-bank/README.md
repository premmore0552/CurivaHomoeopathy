# UPSC & MD Homoeopathy question-bank import

Source: *Solved Multiple Choice Questions: UPSC & MD Entrance Examination (Homoeopathy)* by Dr. V. K. Chauhan, second edition (2011), B. Jain Publishers (P) Ltd., ISBN 978-81-319-1166-2.

The Curiva content owner confirmed permission for public redistribution of this source. Retain this attribution and permission note with any downstream export or redistribution.

## Imported data

- 3,196 numbered question entries from the supplied 1,367-page PDF.
- 3,100 entries have an extractable source answer key and are eligible for scored practice.
- 96 entries remain unscored because the answer key, option layout, or response format is not reliably machine-readable. The text is retained for source review and revision; no missing key is invented.
- Every record stores the question number, book chapter, source PDF page, printed book page where available, original answer text, explanation, exam tag, question format, and extraction-review flags.
- Question stems include text printed on the same line as the question number. The source's OCR/text-layer spelling and spacing are retained rather than silently editorially rewritten.

The import is split across part-01.json through part-11.json and loaded by src/data/chauhanQuestionBank.ts.

## Editorial and scoring boundaries

The book includes single-best-answer, statement-based, matching, sequencing, and assertion/reason questions. Assertion/reason questions use the shared answer code described by the book's preparation guidelines when the individual item does not repeat those options. Matching tables or other layouts that cannot be extracted with confidence are marked for source review.

The 200-question / 2-hour preset is presented as a practice configuration based on the book's approximate preparation guidance, not as a claim about a current official examination pattern.
